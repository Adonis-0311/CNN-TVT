# TVT 支线工作区索引

本目录是 TVT 当前实体 Git 仓库根目录，不使用快捷方式或目录联接。

## 导航

| 层级 | 用途 |
|---|---|
| `01_研究构思与方案` | 现行设计、实验协议和研究本底 |
| `02_实验源码与证据` | 当前完整可复现主线和主要证据快照 |
| `03_投稿版本历史` | 历史稿件实体副本 |
| `04_审稿意见与改稿` | 当前稿件源和稿件图表实体副本 |
| `05_当前稿件与交付` | 最新论文预览和投稿收口材料 |
| `90_统一历史归档` | 停用设计和历史改稿过程记录 |

`02_实验源码与证据/01_当前可复现主线` 是原 `vimd_amc` 的完整实体内容。运行实验时以该目录为工作目录。

两个超过 GitHub 单文件限制的 RML2016.10a 本地数据文件由根 `.gitignore` 排除，目录结构、代码和实验协议仍进入远程版本。
