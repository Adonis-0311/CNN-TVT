# Automatic result-macro derivation audit

`generate_macro_values.py` is the supported producer of the macro-value
manifest. It accepts only `--run-json` and `--output`; it has no argument for a
model name, regime, metric, confidence interval, or performance value.

The generator does not build a cache, load a checkpoint, train a model, or
write inside the formal run directory.

## Runner artifact audit

The final standard runner provides five relevant evidence layers:

| Artifact | Relevant content | Generator check |
|---|---|---|
| `run.json` and per-fit `result.json` | eligibility, exact model/seed matrix, per-regime metrics, A5 mechanism and complexity records | `validate_source_run` first; result files must equal the embedded records |
| `metrics.csv` | one scalar-metric row per model, seed, and evaluation regime | exact row matrix, unique headers/keys, finite cells, cache digest, equality with `run.json` |
| `headline_paired_statistics.csv` | hierarchical seed/source paired differences and intervals | exact candidate/regime matrix, finite cells, seed IDs/count, bootstrap contract, cache digest, and point-estimate equality with metrics and NPZ predictions |
| `ablation_paired_statistics.csv` | six direct A0--A7 hard macro-F1 contrasts in one family, including marginal and simultaneous intervals | exact 33-column schema/order, contrast direction, five ordered seed IDs, class-stratified source hierarchy, 64-hex cache digest, finite positive simultaneous critical value, and deterministic agreement with NPZ predictions |
| `models/*/predictions_*.npz` | probabilities, labels, source IDs, SNR/SIR, split, cache digest | exact array schema, shapes, bounds, finite required metadata, probability normalization, source alignment, and recomputed accuracy/macro-F1 |

Required CSV keys are never inferred by column position. Duplicate columns,
duplicate model/seed/regime rows, missing rows, blank cells, `NaN`, infinity,
or disagreement between evidence layers abort generation before the output
path is created.

## Macro rules

The manifest schema is `vimd_amc.tvt.macro_values.v3`. Its `macros` object
contains exactly **97 provenance records**:

| Group | Count | Deterministic rule |
|---|---:|---|
| `PrimaryReference` | 1 | exact label of the prospectively frozen `comparison_protocol.reference_model`; it must resolve to `cssl_amc_supervised_adaptation` |
| `HeadlineHard{Model}{Metric}` | 25 | five models (`AZero`, `MCLDNN`, `IQFormer`, `CSSL`, `AFive`) by five metrics (`Accuracy`, `MacroFOne`, `WorstRecall`, `NLL`, `ECE`) on `hard_interference` |
| `Regime{Regime}{Field}` | 35 | seven regimes (`Hard`, `UnseenJammer`, `UnseenSpeed`, `HeldoutChannel`, `CombinedOOD`, `CleanACD`, `CleanBE`) by `Reference`, `AFive`, `Gain`, `CILow`, and `CIHigh` |
| A-series hard macro-F1 means | 6 | `HeadlineHardAOneMacroFOne`, `HeadlineHardATwoMacroFOne`, `HeadlineHardAThreeMacroFOne`, `HeadlineHardAFourMacroFOne`, `HeadlineHardASixMacroFOne`, and `HeadlineHardASevenMacroFOne`; A0 and A5 are already present in the headline group |
| Direct ablation contrasts | 18 | `Gain`, `CILow`, and `CIHigh` for each of `AblationTeacher`, `AblationMultitask`, `AblationExactSourceContrast`, `AblationFullVsSingle`, `AblationFullVsDual`, and `AblationBypass`; bounds are the joint family-wise simultaneous 95% bounds |
| Mechanism records | 8 | `MechanismMaskJS`, `MechanismThirdRouteWeightedCorrelation`, `MechanismTargetTransferRatio`, `MechanismTargetAmplificationShare`, `MechanismJammerLeakage`, `MechanismThirdRouteSpearman`, `MechanismThirdRoutePermutationP`, and `OracleSpectralRatioGain` |
| Complexity records | 4 | `VIMDParameters`, `VIMDLatencyPFifty`, `VIMDLatencyPNinetyFive`, and `VIMDLatencyDevice` |

The TeX percentile names deliberately spell out `PFifty` and `PNinetyFive`;
commands containing numeric tokens such as `P50` or `P95` are not valid
members of the contract. Ordinary p50/p95 statistic names in runner artifacts
remain valid. `VIMDLatencyPFifty` and
`VIMDLatencyPNinetyFive` are the medians across formal A5 seed-level p50 and
p95 latency records, respectively, and every seed must record the same frozen
device.

`ResultSource` is generated by the release writer and is not a provenance
record, so an internal/released result file has 98 non-sentinel commands.
Only an eligible release write adds `EligibleLockedResults`, yielding 99
commands in the released file.

There is no baseline-winner record and no post-hoc winner selection.
`PrimaryReference` is the predeclared CSSL-AMC official-architecture
supervised adaptation. IQFormer-inspired remains a required non-oracle
comparator and Holm-family candidate. The CSSL label does not imply a complete
published protocol reproduction, official result, or
structured-interference-specific method.

## Scientific release gate and removed legacy macros

The v3 manifest also contains a top-level `scientific_release_gate`. The
generator derives it from the same JSON/CSV/NPZ evidence and requires:

1. at least +5 pp hard-region macro-F1 for A5 versus each of A0, MCLDNN,
   IQFormer-inspired, and CSSL supervised adaptation;
2. a single six-contrast `hard_ablation_family` on hard-interference
   macro-F1: A3-A2, A4-A3, A5-A4, A5-A1, A5-A6, and A5-A7, all in
   candidate-minus-reference direction, with every family-wise simultaneous
   95% lower bound strictly greater than zero;
3. at least two of three held-factor regimes at +3 pp or more versus the
   predeclared CSSL reference;
4. clean A/C/D and held B/E point gains of at least -1 pp and hierarchical
   95% lower bounds of at least -2 pp; and
5. finite required mechanism values, nonnegative required correlations, and a
   strictly positive oracle-conditioned spectral component ratio.

The validator reconstructs this manifest from the formal artifacts and
requires canonical exact agreement before a release can be written.

The six direct contrasts use one joint, class-stratified hierarchical paired
bootstrap over the exact ordered algorithm seeds `17,29,43,71,101` and the
same aligned test-source clusters. The simultaneous interval method is the
non-studentized
`joint_max_absolute_centered_deviation_hierarchical_paired_bootstrap`, not
bootstrap-t. Its common critical value must be finite and strictly positive.
The 33-column CSV records the lowercase 64-hex cache digest, exact seed
contract, hierarchy, stratification, critical value, and verified source
alignment. Deterministic recomputation from the source-aligned NPZ bundles
additionally verifies source IDs, labels, SNR, SIR, and profile indices. The
compact `run.json` summary binds the family and artifact but is not accepted
as a substitute for that rebuild. A4-A3 is interpreted only as the bundled
jammer/quality/orthogonality intervention, and A5-A6 is a composite control
with no route-count-only causal attribution. These statistics reuse the
frozen A0--A7 jobs, so the formal campaign remains 55 fits.

The old v2 eight-record contract, including its post-hoc winner, compact gain,
single-latency, and feature-SIR names, is obsolete and must fail validation.
The former SDR placeholder also remains prohibited: the runner emits no
waveform SDR endpoint, and the oracle-conditioned spectral ratio diagnostic is
not waveform SIR, SDR, or source-separation evidence. Adding an SDR claim would
require a prospectively defined endpoint, runner-native waveform artifacts, and
a new formal run.

## Commands

Generate a deterministic manifest outside the immutable run directory:

```powershell
& "D:\Python\python.exe" .\tvt_submission\generate_macro_values.py `
  --run-json .\artifacts\tvt_headline_1024_5seed_v1\run.json `
  --output .\tvt_submission\formal_macro_values.json
```

Then run the release preflight:

```powershell
& "D:\Python\python.exe" .\tvt_submission\validate_release.py `
  --run-json .\artifacts\tvt_headline_1024_5seed_v1\run.json `
  --paper-root .\paper `
  --macro-values .\tvt_submission\formal_macro_values.json
```

Both commands exit nonzero on any rejected invariant. Generation leaves
`submission_unlocked=false`; only the separately requested release write may
create `paper/results_auto.tex` and `paper/release_lock.json`. The writer emits
`\EligibleLockedResults` with the fixed value `eligible_locked_formal_run`;
the parser and release-lock-v2 validator both verify it before a public build
can be revalidated. The macro manifest is v3; the release lock remains v2.
