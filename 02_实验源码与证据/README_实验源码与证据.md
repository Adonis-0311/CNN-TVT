# TVT 实验源码与证据

`01_当前可复现主线` 是完整实体工作区，包含源码、实验配置、标准、测试、科学实验日志、正式产物、数据层和稿件。

## 主要路径

- 模型源码：`01_当前可复现主线/src`
- 实验配置与运行：`01_当前可复现主线/experiments`
- 标准与缓存合同：`01_当前可复现主线/standards`
- 自动化测试：`01_当前可复现主线/tests`
- 正式实验产物：`01_当前可复现主线/artifacts`
- 科学实验日志：`01_当前可复现主线/logs`

`03_主要证据` 保存论文数据层与零计算分析的实体快照。约 1.8 GiB 的正式实验产物只在当前主线保留一份。

`data/RML2016.10a_dict.pkl` 和对应 ZIP 原始数据集保留在本地实体工作区，但因单文件超过 GitHub 100 MiB 限制，不进入远程提交；示例代码、协议和其余可复现内容正常上传。
